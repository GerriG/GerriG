## 📌 Actualmente trabajando en...

- 🌱 **Sistema de riego automático**: Sistema embebido de control y supervisión desarrollado sobre **ESP32**.
- ⚙️ Programación en **C++ (Arduino)**, con lectura de sensores, control automático de humedad del suelo mediante histéresis y riego por pulsos.
- 🌡️ Integración de sensores **DHT22** y capacitivos, con compensación climática basada en reglas y datos meteorológicos de **Open-Meteo**.
- 🖥️ Interfaz de usuario mediante pantalla **TFT ILI9341** y panel web local con tecnologías **HTML, CSS y JavaScript**.
- 📡 Conectividad Wi-Fi, servidor HTTP integrado y almacenamiento persistente de configuraciones.
